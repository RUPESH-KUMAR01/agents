What is an agent?

→
LLM / Reason
→
Choose tool?
→

→
Observation
↺
while not finished:
    response = llm(state)

    if response.tool_call:
        result = execute(response.tool_call)

08 · Toy Project 7

Evaluator → Optimizer

→
Evaluator

Score
→

↺
